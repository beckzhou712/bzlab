# 草稿箱

私人草稿区。中文初稿、随手记、还没想清楚的东西都放这儿。

**不会发到网站** —— 三个内容集合的根目录是 `posts/`、`columns/` 和 `pages/`，
这个文件夹是它们的兄弟目录，任何 loader 都扫不到。

**不会推到 GitHub** —— 仓库是 public 的，`.gitignore` 里排除了这个文件夹的
全部内容，只留这个 README。英文稿写好之后，再另建文件到 `posts/<column>/` 下。

## 两个注意事项

**粘进来的图片仍然会上 GitHub。** Obsidian 的附件目录是全局的
（`src/content/attachments/`），那个目录被 git 跟踪，所以在草稿里粘图，图片
本身还是会进仓库 —— 只是没有任何文章引用它。介意的话，草稿阶段就别粘图，
或者把图片手动拖进这个文件夹，它会跟着一起被忽略。

**这里的东西没有备份。** 不进 git 就意味着没有版本历史、不跨设备同步。想长期
留着的稿子，另外存一份。
